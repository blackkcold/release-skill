# Release Skill Files

This directory is the installable skill. Copy it into an agent's skills
directory, or run `../install.sh`.

```

VERSION           single version source
scripts/          release.sh + adapters + existing helpers
config/           defaults and JSON schema
templates/        release note / changelog templates
references/       config, adapters, delta, troubleshooting, migration
```

See `../README.md` for installation, commands and architecture.
